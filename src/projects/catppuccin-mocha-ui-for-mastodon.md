This theme started as a personal customization project and turned into something much bigger once I realized other people wanted a Mastodon interface that felt more intentional too.

I liked the core experience of Mastodon, but I wanted the web UI to better match the visual language I already enjoy using elsewhere.

## What I focus on with it

- A more cohesive interface built around the Catppuccin palette
- Better support for different layout preferences
- A setup that is easier to install and maintain than the first pass

## Why it stays interesting

Theme work is fun because it sits between design and usability. Small spacing changes, color choices, and layout decisions can make the whole product feel different.

That makes this project a good place for me to refine interface ideas while still shipping something people can actually use.
