StylePort is a Safari-first UserCSS manager for people who want more control over how the websites they visit look.

It combines a macOS container app with a Safari extension. The app provides the visible home for setup and status, while the extension matches selected styles to websites and applies their compiled CSS.

## What it does

- Import plain CSS and UserCSS from a file, URL, or pasted text
- Configure variables supplied by a UserCSS theme
- Match styles to precise websites and URL patterns
- Edit installed styles and check their update URLs
- Export styles and restore backups
- Explain Safari permissions and extension status clearly

## Local and account-free

StylePort stores styles, variables, and preferences in Safari's local extension storage on your Mac. It does not require an account and has no behavioral analytics, advertising, or cross-app tracking. Optional tips use purchase reporting, but do not send your styles or browsing history to the developer or RevenueCat.

Safari website access is required to apply the styles you select. You remain in control of that permission through Safari Settings and can restrict or revoke it at any time.

Only install styles from sources you trust: imported CSS can reference external resources. StylePort changes website appearance, not Safari's own interface or protected browser pages.

## Availability

StylePort is available now for Safari on macOS 14 and later, both directly from the StylePort website and on the Mac App Store. The direct release is Developer ID-signed and Apple-notarized. It uses a signed Sparkle feed for updates and asks before installing them; the App Store edition receives updates through Apple.

Both editions include every feature for free. There is no subscription or paid feature tier. Voluntary one-time contributions and optional App Store tips support development without unlocking a different edition.

TestFlight is a separate beta-testing option for previewing future updates. The StylePort website has current downloads, support, privacy details, and the public roadmap.
