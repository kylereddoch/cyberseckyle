# Donation badges

These static SVGs are unchanged copies of successful Shields.io responses recovered
from the site's Eleventy image cache on November 6, 2026. Hosting them locally
preserves the existing badge artwork without requiring Shields.io during builds
or page visits. The article's donation destinations are unchanged.

Original sources:

- `github-sponsors.svg`: https://img.shields.io/badge/GitHub%20Sponsors-Support-1f6feb?logo=githubsponsors&logoColor=white
- `ko-fi.svg`: https://img.shields.io/badge/Ko--fi-Support-ff5f5f?logo=kofi&logoColor=white
- `buy-me-a-coffee.svg`: https://img.shields.io/badge/Buy%20Me%20a%20Coffee-Support-ffdd00?logo=buymeacoffee&logoColor=000000
