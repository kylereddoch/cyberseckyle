# Kyle's Tech Korner

My personal blog, built with [Eleventy](https://www.11ty.dev/) and
deployed on [GitHub Pages](https://pages.github.com).\
This site is a migration from Weblog by OMGlol, rebuilt with the
[Eleventy Excellent
theme](https://github.com/madrilene/eleventy-excellent) as a foundation
and then heavily customized.

## Features

This blog includes:

-   Clean, lightweight Eleventy build with GitHub Actions workflow for
    deployment\
-   [Eleventy
    Excellent](https://github.com/madrilene/eleventy-excellent) starter
    as a base\
-   Automated deploys to GitHub Pages with custom domain
    (`kylereddoch.me`)\
-   Custom filters and helpers (like reading time and build time
    indicators)\
-   Syntax highlighting with custom token colors and Catppuccin-inspired
    palette\
-   Accessible dark/light mode via `prefers-color-scheme` and theme
    toggle\
-   Mastodon "Discuss this post" integration under each article\
-   Automated RSS feed and sitemap

## Development

Clone and install dependencies:

``` bash
git clone https://github.com/kylereddoch/kylereddoch.me.git
cd kylereddoch.me
npm install
```

Run locally:

``` bash
npm start
```

Create a production build:

``` bash
npm run build
```

Deploys are handled automatically via GitHub Actions to the `gh-pages`
branch.
